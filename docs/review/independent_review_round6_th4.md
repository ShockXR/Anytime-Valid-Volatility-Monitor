### M1. Theorem 3 is false as stated: the `D*` term needs the maximum over the horizon and a G-measurable drift

* **Where.** `docs/theory_robustness.md:136` to `:142` (statement and proof), used at `:144` to `:148`, `:272` to `:289` (switching) and the status row `:388`; summarised at `docs/report_parts/TH4.md:11`.
* **Evidence.**
  1. *The maximum.* Lemma 2 defines `D*_t` as the largest product over windows that *end at t* (`:112`). Theorem 3 bounds `P(T ≤ m | G)` by `D*_m m / A`, and the proof applies Theorem 2 "with the `H_0`-measurable choice `K = D*_m`" (`:142`). Theorem 2's remainder `P(max_{t ≤ m} D*_t > K)` vanishes only for `K = max_{t ≤ m} D*_t`. Counterexample with a deterministic drift path (G trivial, so the drift is G-measurable): `Y_t = B` for 7 steps, then `Y_t = 0.95`. The default detector alarms at step 7, so `P(T ≤ 390) = 1`. The window products ending at step 390 are at most 17.5, so `D*_390 × 390 / 7800 = 0.876`: the bound as written is below the probability. The maximum over t is 80,628. The code uses the maximum (`drift_cusum` returns the running maximum; `run_paths` stores `run`), so no reported value is affected.
  2. *G-measurability.* The proof needs K to be `H_0`-measurable, so the drift that builds `D*` must be known given G. The statement asks this only of the bounds `δ↑_t, δ↓_t` and builds `D*` from "the signed drift given G", `E[Y_t | F_{t-1} ∨ G] - 1`, which is only `H_{t-1}`-measurable in general. Counterexample (G trivial; the hypotheses hold with the deterministic bounds `δ↑_1 = 0`, `δ↑_t = B - 1` for t = 2 to 7, `δ↑_t = 0` afterwards, `δ↓_t = 0`): `Y_1 = B` with probability 1/B and 0 otherwise; after `Y_1 = B` the stream stays at B until the alarm at step 7 and then at 1; after `Y_1 = 0` it stays at 1. The first term of Theorem 3 is 0.523 at m = 390. The `D*` term built from the signed drift is at least 1 on the first kind of path and `m / A = 0.05` on the second. So the expectation of the right side over the drift path (the "Hence" of `:140`) is `(1/B) 0.523 + (1 - 1/B) 0.05 = 0.1023`, against `P(T ≤ 390) = 1/B = 0.1106` (at m = 7: 0.0532 against 0.1106). (`counterexamples.py` reproduces the second and third with `run_paths` and in closed form; the example of item 1 was checked with `drift_cusum` and `run_paths`.)
  3. In the three examples of `:146` to `:148` and in the switching experiment the drift given G is a function of G, so the corrected theorem covers every value reported as proved.
