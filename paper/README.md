# Paper draft

Draft of a paper on the monitor in this repository: *Anytime-valid detection of volatility changes in high-frequency returns with robust truncation* (Shreyan Thanki, draft of November 2026), with a supplement and a companion note on extensions. This version follows the restructuring asked for in the referee report `docs/review/referee_report_paper.md` (Section 5 and items M1 to M8, 1 to 21 and m1 to m35) the second report `docs/review/referee_report_paper_round2.md` (J1 to J3, F1 to F20, the four inconsistencies and the minor points it lists as open) and the third report `docs/review/referee_report_paper_round3.md` (K1 and k1 to k15).

```bash
pandoc -s --shift-heading-level-by=-1 short_paper.md -o short_paper.tex
```

`--shift-heading-level-by=-1` turns the Markdown `##` headings into LaTeX `\section`. The section numbers are written in the headings, and the pandoc template switches LaTeX numbering off, so they are not doubled. The `.tex` was produced with pandoc 3.1.3. The PDF was rebuilt from this version with `python scripts/build_paper_pdf.py` on 3 November 2026 (referee m10 and k16).

## Compiling the LaTeX elsewhere

With a TeX distribution that has the usual packages of the pandoc template (`amsmath`, `amssymb`, `graphicx`, `longtable`, `booktabs`, `hyperref`, `xcolor`), run from this folder:

```bash
cd paper
pdflatex short_paper.tex && pdflatex short_paper.tex
# or: xelatex short_paper.tex (or lualatex), twice
```

or go straight from the Markdown:

```bash
cd paper
pandoc -s --shift-heading-level-by=-1 short_paper.md -o short_paper.pdf --pdf-engine=xelatex
```

For a journal template, copy the body of `short_paper.tex` (between `\begin{document}` and `\end{document}`) into the template, replace the hand-written reference list by `\bibliography{references}` with the template's author-year style (for example natbib), and turn the in-text citations into `\citet`/`\citep` commands. The keys in `references.bib` are of the form `surnameYEARword` (for example `shin2024edetectors`). The supplement is the part of `short_paper.md` after the heading "Supplementary material"; a journal will usually want it as a separate file.
